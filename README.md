# Conan Manager

Веб-панель для нескольких серверов **Conan Exiles Dedicated Server (UE5)** на
одной Linux-машине. Ставит и обновляет игру через SteamCMD, держит каждый
сервер отдельным systemd-юнитом, поднимает после падения и после перезагрузки
хоста, останавливает с проверкой целостности базы мира, управляет модами из
Steam Workshop, пишет в Discord и Telegram и умеет говорить с игроками по RCON.

Один бинарник без внешних зависимостей: панель, API и SQLite внутри него.

## Что умеет

**Серверы.** Установка и обновление через SteamCMD, запуск/остановка/рестарт,
перезапуск после падения (до 3 раз за 30 минут), восстановление состояния
после перезагрузки хоста, детект зависшего процесса по query-порту, остановка
по схеме «SIGTERM → ожидание → kill → `PRAGMA integrity_check`» с блокировкой
запуска, если база повреждена.

**Моды.** Список с порядком загрузки, загрузка всего набора одним запуском
SteamCMD, общий кеш с жёсткими ссылками (один мод на хосте — одна копия),
импорт коллекции и списка через запятую, `modlist.txt` пишется за вас,
обновление вместе с игрой.

**Конфиги.** Редактор любого INI игры с подсветкой и историей версий,
посекционная правка полей, уровни логов Unreal.

**Расписание и оповещения.** Плановые рестарты и остановки (интервал, время
суток, cron, часовые пояса), предупреждения игрокам в чат за N минут,
отложенный рестарт, уведомления в Discord, Telegram и на свой HTTP-адрес —
с отдельным текстом на каждое событие.

**Наблюдение.** Нагрузка процесса и всей машины, FPS и онлайн из отчётов игры,
история за час, журнал событий, чтение логов с конца, журнал аудита.

**Бэкапы.** Копия мира без остановки сервера (`VACUUM INTO`), контрольные
суммы, бэкап перед каждым обновлением, восстановление любой копии.

**Доступ.** Вход с сессиями в базе, CSRF, ограничение попыток, список
разрешённых адресов, HTTPS сам или через Caddy/nginx, строгая CSP.

## Требования

- Ubuntu 22.04 или 24.04 (другой systemd-дистрибутив, скорее всего, тоже
  подойдёт, но проверялось на Ubuntu);
- Go 1.24+ для сборки;
- место под игру: около 30 ГБ на сервер плюс моды;
- оперативная память: сервер без модов — около 4 ГБ, с набором модов легко
  доходит до 10 ГБ.

## Установка

```bash
git clone https://github.com/Myp3uK/ConanLinuxManager.git
cd ConanLinuxManager
./scripts/build.sh
sudo ./install.sh --domain manager.example.com
```

`install.sh` заводит системного пользователя, каталоги, файл окружения и
systemd-юнит, а с `--domain` ещё и Caddy с сертификатом Let's Encrypt. Без
`--domain` панель слушает только localhost — ходить к ней через SSH-туннель.
Полезные ключи: `--no-deps` (не ставить пакеты через apt), `--help`.

Логин и пароль администратора печатаются в конце установки и лежат в
`/etc/conan-manager/conan-manager.env`. Пароль смените при первом входе.

Подробнее, включая установку из пакета: [docs/install.md](docs/install.md).

## Обновление

```bash
git pull
./scripts/build.sh
sudo ./install.sh --domain manager.example.com --no-deps
```

Серверы при этом не останавливаются: каждый живёт в своём systemd-юните и
переживает перезапуск менеджера.

## Настройка

Всё в `/etc/conan-manager/conan-manager.env`; образец с комментариями —
[deploy/conan-manager.env.example](deploy/conan-manager.env.example). Там
адрес и порт панели, администратор, ключ шифрования для вебхуков, каталоги
бэкапов и кеша модов, доверенные прокси и список разрешённых адресов. Часть
настроек меняется прямо в панели, на странице «Панель».

## Состояние

Работает на живом сервере: установка, обновления, моды, расписания,
уведомления и бэкапы проверены на настоящем Conan Exiles UE5, а не только
тестами. Не сделано: внешние хранилища бэкапов (SFTP, rsync, S3) и бэкап по
расписанию, счётчик игроков без RCON, установка одной командой и
самообновление. Полный список — в [ROADMAP.md](ROADMAP.md).
